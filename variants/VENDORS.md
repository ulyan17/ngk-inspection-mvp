# Заявления подрядчиков

Четыре компании прислали MVP робота-инспектора для насосной станции. Ниже — то, что каждая пишет о своём решении в коммерческом предложении. **Ваша задача на воротах — проверить эти заявления измерениями, а не поверить им.**

| | Подрядчик | Что заявляет | Запуск |
|---|---|---|---|
| **А** | «Быстрый обход» | «Самый быстрый робот на рынке: полный обход станции за 2,5 минуты. Один точный замер на точку — больше не нужно.» | `python -m ngk_sim run --variant A` |
| **Б** | «Надёжный» | «Стопроцентная точность показаний и ни одной ложной тревоги. Если датчик хоть немного сомневается — подключаем оператора, он перепроверит.» | `python -m ngk_sim run --variant B` |
| **В** | «Сбалансированный» | «Выполняем все обязательные критерии заказчика. Повтор недоступной точки, три замера, медиана, перегрев подтверждаем по пятну в нескольких кадрах.» | `python -m ngk_sim run --variant C` |
| **Г** | «Оптимальный маршрут» | «Лучшие KPI среди всех: короткий маршрут, адаптивные замеры, все точки проверены, ни одной ложной тревоги, без участия оператора.» | `python -m ngk_sim run --variant D` |

Код каждого подрядчика лежит в `variants/<буква>_…/mission.py`. Читать его не обязательно, но иногда одна строчка в коде объясняет то, что вы увидели в анимации.
