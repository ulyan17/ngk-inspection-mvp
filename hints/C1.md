# Подсказки к C1 — миссия

Открывайте по одной. Сначала попробуйте сами.

<details><summary>Подсказка 1 — что происходит</summary>

Запустите `python -m ngk_sim run --seed 19` и посмотрите в лог: `Nav2: нет пути до (28.0, 5.0)` и `K2: не доехал (FAILED)`.
Тупик с K2 перекрыт техникой (оранжевый прямоугольник). Через какое-то время техника уезжает, но к этому моменту baseline уже забыл про K2.
</details>

<details><summary>Подсказка 2 — идея</summary>

`queue` — обычный список. Если точку не удалось посетить, её можно положить в **конец** очереди: робот сначала объедет остальные точки, а к K2 вернётся позже.
Чтобы не зациклиться, считайте попытки в `attempts[cp.id]` и сравнивайте с `MAX_RETRIES`.
</details>

<details><summary>Подсказка 3 — почти решение</summary>

```python
MAX_RETRIES = 1

if result != TaskResult.SUCCEEDED:
    attempts[cp.id] += 1
    if attempts[cp.id] <= MAX_RETRIES:
        queue.append(cp.id)
    else:
        publish_unknown(ctx, cp, "unreachable")
    continue
```
</details>

<details><summary>Бонус — если K2 оказалась последней в очереди</summary>

Тогда повтор случится сразу, и проезд ещё будет закрыт. Подождите на месте: `ctx.wait(30)` перед повтором, если других точек в очереди нет.
А порядок «ближайший сосед» в `plan_route()` сокращает путь: из текущей точки едем к ближайшей непосещённой (`math.hypot`).
</details>
