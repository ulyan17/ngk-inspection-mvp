<details><summary>Подсказка 1 — что проверяет валидатор</summary>

`python -m ngk_sim validate out/seed_19/report.json` пишет, каких полей не хватает.
В `summary` нужны: `checkpoints_total`, `checkpoints_inspected`, `coverage`, `anomalies`, `alarms`.
«Проверена» — статус `OK` или `ANOMALY`. `coverage = checkpoints_inspected / checkpoints_total`.
</details>

<details><summary>Подсказка 2 — почти решение для summary</summary>

```python
inspected = sum(1 for c in checkpoints if c["status"] in (Status.OK, Status.ANOMALY))
summary = {
    "checkpoints_total": len(checkpoints),
    "checkpoints_inspected": inspected,
    "coverage": round(inspected / len(checkpoints), 3),
    "anomalies": sum(1 for c in checkpoints if c["status"] == Status.ANOMALY),
    "alarms": len(alarms),
}
```
